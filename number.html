Fi and Lu wonder: What is a Number?

Having explored a wide variety of math concepts, Fi and Lu began to wonder what things should be called numbers. Of course there are the counting numbers: 0, 1, 2, 3,… which everyone recognizes as numbers. These numbers can be added and multiplied, but when we try to undo addition, we have to include negative numbers and so end up with all the integers. Similarly, when we then try to undo multiplication, we have to include fractions and so end up with all the rational numbers. We’ve seen how the rational numbers can be laid out on a line. And we’ve seen that there are points on that line that don’t correspond to rational numbers even though we can find rational numbers arbitrarily close. When we include all those points, we end up with the real numbers, and we call the line of real numbers the real line. Most everyone thinks that real numbers are numbers.

Later, Fi & Lu saw how to escape the real line and find complex numbers that also can be added and multiplied, subtracted and divided. But unlike real numbers, there isn’t a natural linear ordering of complex numbers. So are complex numbers still numbers?

Even the complex plane can be escaped, but we have to add two more dimensions and give up yet another property. Multiplication can no longer be commutative: \(a\times b\) is not always the same as \(b\times a\) for quaternions. So, are quaternions still numbers?

Mathematicians have listed various properties that numbers might possess, and named various structures that possess some or all of those properties. The structures comprise one or more sets of objects and one or more operators on those objects (such as addition (usually written as \(+\)), multiplication (usually written as \(\times\) or \(\cdot\) when not implicit), negation (aka additive inverse) (usually written \(-x\)), (multiplicative) inverse (often written \(x^{-1}\)), subtraction (usually written as \(-\)), and division (sometimes written as \(\div\) or \(/\)), as well as comparison operators (\(=\ \neq\ <\ \leq\ \geq\ \gt\))). Sometimes a set of objects has one or more special elements, such as an additive identity (usually written as \(0\)), or a multiplicative identity (usually written as \(1\)). Negation requires an additive identity, and inverse requires a multiplicative identity. Note that, typically, subtraction and division are not specifically included; rather subtraction is just addition with negation of the second argument, and division is just multiplication with the inverse of the second argument. Similarly, the equality operation (\(=\)) is implicit, and if there is an ordering, only ‘less than’ (\(<\)) is explicit, with all the others (\(\le\ \geq\ >\)) being implicit.

The below table lists a few common structure types. All the operators listed are associative, i.e., \(a+(b+c) = (a+b)+c\) and \(a\times(b\times c) = (a\times b)\times c\). And for the listed structures with both \(+\) and \(\times\), multiplication distributes over addition, i.e., \(a\times (b+c) = (a\times b) + (a\times c)\) and \((a+b)\times c = (a\times c) + (b\times c)\). The operators required to be commutative for the listed structures are listed as commutative operators; commutativity is not prohibited from other structures’ operators. Similarly, even if multiplicative inverses (\(x^{-1}\)) are not listed, some elements may still have inverses. Even when multiplicative inverses are listed, \(0\) never has a multiplicative inverse. So fields are division rings, and division rings are rings, while abelian groups are groups (so that using \(+\) for the operator is not required). You may note that a ring with just its addition operator forms an abelian group; and a division ring without its \(0\) and together with its multiplication operator forms a group.

You may have noticed that, except for \(\mathrm{S}_n\), all the examples above are infinite structures. Are there any finite structures whose elements could be called numbers? A clue emerges when we watch a 24-hour clock. The hour advances from 0 through 23 and then repeats. If we want to know the hour that is \(h\) hours in the future, we add \(h\) to the current hour and take the remainder when divided by 24.

More generally, we can choose any integer \(m > 0\) and represent each integer \(x\) with its remainder when divided by \(m\), written \(x\bmod m\). We can then modify addition and multiplication by replacing the usual result by its remainder when divided by \(m\). This is called clock arithmetic, more formally known as modular arithmetic with modulus \(m\). It’s not hard to see, at least for \(m > 1\), that the resulting structure comprising \(0\) through \(m-1\) is a ring, usually written as \(\mathbb{Z}/m\mathbb{Z}\). It turns out that if \(m\) is prime, it’s a field!

There are other finite fields. In fact, for any prime \(p\) and integer power \(n > 0\), there is exactly one field with \(p^n\) elements, \(\text{GF}(p^n)\). We've already seen that \(\text{GF}(p) = \mathbb{Z}/p\mathbb{Z}\); for \(n>1\), \(\text{GF}(p^n)\) is harder to describe, and we have a choice how to write the elements—while it’s natural to write \(0,1,\dots,p-1\) for the corresponding sums of repeated \(1\)s, we have choices for the other elements. Note that if you sum \(p\) copies of any element of \(\text{GF}(p^n)\), the result is \(0\); \(p\) is called the characteristic of the field.

Representing numbers

In school, we learn about decimals, which is a way of representing real numbers. Decimal representation is an example of positional notation, where the value of a digit depends on where it is placed. Decimal representation is also called base ten or radix ten, since each digit is worth ten times as much as it would be if it were one place to the right. We use a period (called a decimal point) to separate the one’s place from the tenth’s place. As you might guess, there’s nothing special about ten, and any integer base greater than one can be used as a radix, as long as you have radix-many symbols to serve as “digits”. The simplest radix is two (known as binary), for which we only need two symbols: 0 and 1 (called bits). The addition and multiplication tables are rather easy to memorize; the only downside is that you generally need over three times as many binary bits as decimal digits to represent the same number. For humans, we can group the bits in threes (for radix eight, or octal, using digits 0 through 7 as symbols) or fours (for radix sixteen, or hexadecimal, using digits 0 through 9 and letters a through f as the sixteen symbols). When it’s not obvious what the radix is, the radix as represented in decimal is subscripted to the representation, e.g., \(69_{16} = 105_{10}\) and \(105_8 = 69_{10}\).

You might note that plain positional notation can only represent nonnegative real numbers. Negative numbers are represented by preceding the corresponding positive number’s representation with a minus sign. What you might find amazing is that you can use \(i-1\) as a radix, and just the bits 0 and 1, to represent any complex number, with no other symbols required besides a mark (typically a period or comma) to demarcate the one’s place. Doing arithmetic with this representation is a bit complicated, because two is represented as 1100, i.e., \(1+1=1100_{i-1}\). To get a sense of radix \(i-1\), we sequentially display on the complex plane below the first 257 nonnegative integers as written in binary but interpreted as radix \(i-1\).

When is \(\mathbb{Z}/m\mathbb{Z}\) a field?

For \(\mathbb{Z}/m\mathbb{Z}\) to be a field, every nonzero element must have an inverse. If \(m\) is not prime, it is the product of two smaller nonzero integers: \(m=ab\). So, in \(\mathbb{Z}/m\mathbb{Z}\), \(ab=0\). If \(b\) had an inverse, we’d have \(a = abb^{-1} = 0b^{-1} = 0\), but \(a\) is a nonzero integer less than \(m\), so can’t be \(0\bmod m\). So there are nonzero elements without inverses, so \(\mathbb{Z}/m\mathbb{Z}\) is not a field.

But what if the modulus is prime?

It’s not hard to show that the greatest common divisor of two integers is a linear combination of those two integers. There’s a lovely proof of this:

  • Consider the set of all linear combinations of \(a\) and \(b\): \(S = \{xa+yb\ |\ x\in\mathbb{Z}\ \&\ y\in\mathbb{Z}\}\).
  • Let \(g = ua+vb\) be the least positive element of \(S\).
  • Let \(r\) be the remainder when \(a\) is divided by \(g\), so \(a=qg +r\) with \(0 \leq r < g\).
  • So \(r = a-qg = (1-u)a-ub\) is also in \(S\) and it’s less than \(g\). Since \(g\) is the smallest positive element of \(S\), \(r\) must be \(0\), i.e., \(g\) is a divisor of \(a\).
  • A similar argument shows that \(g\) is a divisor of \(b\).
  • Since any common divisor of \(a\) and \(b\) clearly divides every element of \(S\) and in particular divides \(g\), \(g\) must be the greatest common divisor of \(a\) and \(b\).

In fact, the Euclidean algorithm, which Fi & Lu learned about when investigating Fibonacci numbers, can be extended to find \(u\) and \(v\) in addition to \(g\) when given \(a\) and \(b\):

So, if \(p\) is prime, then \(\gcd(h,p)=1\ \text{for}\ 0 < h < p\), so \(1 = uh+vp\), so \(uh=1\bmod p\), i.e., \(u\) is the inverse of \(h\). So each nonzero element has an inverse, and so \(\mathbb{Z}/p\mathbb{Z}\) is a field, also known as the Galois field of order \(p\) or \(\text{GF}(p)\).
